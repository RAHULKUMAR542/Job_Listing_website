## 📌 Project Overview

The Job Listing Website allows users to:

- View job openings in a clean card layout
- Search jobs by keyword
- Filter jobs by location, category, and experience level
- View detailed job information in a modal
- Save jobs for later using localStorage
- Navigate through job listings using pagination

The website is fully responsive and works across desktop, tablet, and mobile devices.

---

## ✨ Features

### 1️⃣ Job Cards
- Displays job title
- Company name
- Location
- Experience level
- View More button (opens modal)
- Save Job button

### 2️⃣ Filters
- 🔍 Search by Job Title
- 📍 Filter by Location
- 🏷 Filter by Category
- 🎓 Filter by Experience Level
- ❌ Clear All Filters option

### 3️⃣ Interactive Features
- Dynamic filtering without page reload
- Pagination for large job listings
- Modal popup for detailed job view
- Save jobs using browser localStorage

### 4️⃣ Responsive Design
- Mobile-friendly layout
- Flexible grid system
- Clean and modern UI
